# nathanaelnienaber.com

Personal site for [nathanaelnienaber.com](https://nathanaelnienaber.com).

This repository is separate from [attunedholdings.com](https://github.com/nathanaelnienaber/attunedholdings.com).

## Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Connect this repo to a **new** Vercel project at [vercel.com/new](https://vercel.com/new), then add the `nathanaelnienaber.com` domain when ready to go live.
